# Inputs

All paths are relative to `$SGMA2_DATA` (default `./data`) unless stated.

OSF project layout (the project root is `$SGMA2_DATA`):

```
feature_tables/    feature tables, blocklists, arg_reclust/
posthost_qc/       read accounting, decontam_metadata.tsv, 646_metag-prep-info.txt
metadata/          sample_household_key.tsv, software_versions.tsv, ICRAF validation table
household/         household metadata (also $SGMA2_HOUSEHOLD), long/, sgma2_variableindex.csv
assembly/          assembly_manifest.tsv, control_manifest.tsv
microbecensus/     analysis_samples.txt
fastq/             sample_list.tsv
sgma2_codebook.csv variable-level codebook for the household files
```

## Feature tables: `feature_tables/`

Built in the HPC pipeline and archived at OSF [10.17605/OSF.IO/3G2Z5](https://doi.org/10.17605/OSF.IO/3G2Z5).

| File | Built by | Columns / content |
|---|---|---|
| `cohort_phylum.tsv`, `cohort_genus.tsv`, `cohort_species.tsv` | `pipeline/03_taxonomy-woltka` | Woltka read counts, `#FeatureID` x sample |
| `metaphlan_classified_summary.tsv` | `pipeline/04_taxonomy-metaphlan` | `sample_id, compartment, pct_unclassified, pct_classified, n_species` |
| `ko_abundance_wide.tsv.gz`, `ko_abundance_wide_cf50.tsv.gz` | `pipeline/09`, `pipeline/11` | KO x sample read counts; `_cf50` keeps gene x sample cells with covered fraction >= 0.5 |
| `arg_abundance_wide.tsv.gz`, `arg_abundance_wide_cf50.tsv.gz` | `pipeline/10`, `pipeline/11` | ARG family (AMRFinderPlus element symbol) x sample read counts |
| `arg_annotation.tsv` | `pipeline/10` | `arg_symbol, tool, element_type, scope, drug_class, subclass, n_genes` |
| `arg_hits_long.tsv.gz` | `pipeline/10` | `gene_id, tool, arg_symbol, arg_name, scope, element_type, element_subtype, drug_class, subclass, method, pct_coverage, pct_identity, ref_accession` |
| `arg_gene_abundance.tsv.gz` | `pipeline/11` | `gene_id, sample_id, count, covered_fraction` for the ARG-bearing catalog genes |
| `arg_reclust/arg_id{95,90,85,80}_cluster.tsv` | `pipeline/11` | representative, member (no header) |
| `control_features_blocklist.tsv` | `pipeline/11`; ARG rows of `controls/control_features_blocklist.CANDIDATE.tsv` with `max_count_in_negative_control` >= 5 | `feature, feature_type, max_count_in_negative_control, n_negative_controls`; ARG families detected at >= 5 reads in any negative control |
| `control_arg_genes_blocklist.tsv` | `pipeline/11`; rows of `controls/control_arg_genes_blocklist.CANDIDATE.tsv` with `max_count_in_negative_control` >= 5 | `gene_id, arg_symbol, max_count_in_negative_control, n_negative_controls` |
| `microbecensus_ge.tsv` | `pipeline/13` | `sample_id, average_genome_size, genome_equivalents` |
| `background_gene_summary.tsv.gz`, `arg_gene_lengths.tsv` | `pipeline/12` | per-gene prevalence, abundance, length, eggNOG OG and KO for the background pool; ARG gene lengths (no header) |
| `background_abundance*.tsv.gz` | `pipeline/12` | `gene_id, sample_id, count, covered_fraction` for the selected background genes |
| `single_copy_marker_kos.tsv` | `analysis/01_build_single_copy_markers.R` | 57 ribosomal-protein KOs; downloads the KEGG BRITE file if absent |

`background_gene_summary.tsv.gz` (about 360 MB) and `background_abundance*.tsv.gz` (about 150 MB)
are the largest; they are deposited, or regenerated by `pipeline/12_background-genes`.

## Sample sheets: `posthost_qc/` and `metadata/`

| File | Content |
|---|---|
| `posthost_qc/sgma2_step1_read_accounting.tsv` | built by `pipeline/02`; per-library raw, post-fastp and post-host read counts and per-host removal |
| `posthost_qc/decontam_metadata.tsv` | 256 rows: `sample_id, compartment, field_name, field_suffix, sample_type, is_neg_control, usable_for_prevalence, gdna_conc, posthost_reads, pos_dup_of, is_donor`. `sample_type` is `true_sample`, `neg_blank`, `pcr_blank`, `pos_dup` or `mock`. Also the source of the assembly and MicrobeCensus manifests (true samples with >= 20M post-host reads for assembly). |
| `posthost_qc/646_metag-prep-info.txt` | library prep sheet: `sample_name, sample_plate, well_id, run_id, ...`. `pipeline/02_post-host-qc-accounting/01_build_samplesheet.sh` reads it from `$SGMA2_BASE/646_metag-prep-info.txt`; analysis scripts read this copy |
| `metadata/sample_household_key.tsv` | `sample_id, compartment, field_name, household, sample_type, posthost_reads`; the key every analysis script loads |
| `metadata/software_versions.tsv` | `stage, tool, version, database, role`; source of Supplementary Table S7 |
| `metadata/icraf_J62_report_table2_validation.tsv` | `icraf_property, our_variable, model, r2_val, rmse_val, bias_val, rpiq_val`; transcribed from Table 2 of soil spectral report provided by ICRAF |

Other cluster inputs (in the OSF project, not in the repository): `fastq/sample_list.tsv`
(sample, R1, R2), `assembly/assembly_manifest.tsv` (sample, compartment),
`assembly/control_manifest.tsv` (control sample, control type),
`microbecensus/analysis_samples.txt` (194 analysed sample ids).

In `fastq/sample_list.tsv` the R1 and R2 paths start with the literal text `$SGMA2_BASE`. Expand it
before use: `export SGMA2_BASE=/path/to/scratch/sgma2; envsubst < sample_list.tsv > $SGMA2_BASE/fastq/sample_list.tsv`.

## Household metadata: `$SGMA2_HOUSEHOLD`

De-identified household, child and soil metadata, archived at OSF [10.17605/OSF.IO/3G2Z5](https://doi.org/10.17605/OSF.IO/3G2Z5).

| File | Used by |
|---|---|
| `sgma2_fieldmetadata.csv` | `prepare_household_tables.R` (only `hq_uuid` and `hh_id`) |
| `long/sgma2_hq_{animalroster,animalconfinementpractices,childanimalcontact,childfecescontact,hhmembersroster}.csv` | `prepare_household_tables.R` |
| `sgma2_hq_module1_childhhdemographics.csv` | `prepare_household_tables.R` |
| `sgma2_hq_*_wide.csv`, `sgma2_hq_module1_hhdem_agestructure.csv` | written by `prepare_household_tables.R`; read by `05`, `15`, `16` |
| `sgma2_hq_module2_hhses.csv`, `module3_hhwash`, `module4_hhanimalhusbandry`, `module5_childhealth`, `module6_hhffq`, `module7_24hrrecall` | exposure panel (`05`, `15`), diet (`17`) |
| `sgma2_screening.csv`, `sgma2_stoolmetadata.csv`, `sgma2_childanth.csv` | `16_child_covariates.R` |
| `sgma2_soiledaphicproperties.csv` | `05` (soil properties), `12` |

Question wording for every variable is in `sgma2_variableindex.csv`.
Run `Rscript analysis/prepare_household_tables.R` once before the analysis. One household entered
animal names in Swahili (`Ng'ombe`, `Kuku`); the script recodes them to `Cows` and `Chickens`.
